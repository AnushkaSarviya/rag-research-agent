## 💡 Tips for Choosing

1. **Keep it short** (2-4 words)
2. **Use hyphens** (GitHub standard)
3. **Be specific** (mention key tech if space allows)
4. **Make it searchable** (use common terms like "rag", "ai", "chatbot")
5. **Avoid jargon** (unless targeting very technical roles)
